# Yixiang Ren – EGR 304 Individual Datasheet (Team 107)

Source for the individual datasheet website of the **Arm Motion Control** subsystem of Team 107's Simple Educational Robotic Arm (EGR 304, Fall 2026, Arizona State University).

* Website: <https://crackoxide.github.io/CrackOxide_EGR304_Fall26.github.io/>
* Team report: <https://egr304-2026-f-107.github.io/>

The site is built with MkDocs Material from the `docs/` folder by the GitHub Action in `.github/workflows/`. Each assignment has its own folder under `docs/` (block diagram, component selection, BOM, schematic, power budget); datasheets are in `docs/Appendix/Datasheets/`.
